📲 TaskDispatcher · 无线 ADB 初次连接步骤
1 准备工作

确保满足以下条件：

  • 一台 Windows 电脑（已安装 TaskDispatcher，内置 ADB 工具）
  • 一部 Android 手机（版本 8~16 均可），USB 数据线
  • 手机和电脑连接同一个 Wi-Fi 网络（同一网段）
  • 手机已开启开发者选项和 USB 调试
💡 如何开启开发者选项：设置 → 我的设备 → 全部参数 → 连续点击「OS版本 / MIUI版本」7 次。
返回设置 → 更多设置 → 开发者选项 → 打开 USB 调试。
2 用 USB 线连接手机与电脑

使用数据线将手机连接到电脑。手机上会弹出 「允许 USB 调试？」 对话框，勾选 「一律允许」 并点击「确定」。

确保连接模式为 「文件传输 (MTP)」（部分旧机型需要手动切换）。

⚠️ 小米 MIUI / HyperOS 用户：务必登录小米账号并联网，然后在开发者选项中开启 「USB 调试（安全设置）」，否则后续 input tap 等指令将被拦截。详见下方限制说明。
3 点击「连接手机」按钮

启动 TaskDispatcher 程序，点击右下角的 「连接手机」 按钮。

程序将自动将手机 ADB 从 USB 模式切换为无线模式

💡 如果弹出错误提示「请重新插拔手机 USB 线，并在手机上选择传输文件模式」，说明 ADB 未正确识别手机。请检查 USB 调试授权和连接模式后重试。
4 输入手机局域网 IP 地址

在弹出的 「无线连接」 对话框中输入手机的 Wi-Fi IP 地址并点击「确定」。

查看手机 IP：设置 → WLAN → 点击当前连接的 Wi-Fi → 查看 IP 地址（例如 192.168.1.105）。

点击「确定」后，程序将连接设备。

⚠️ 手机和电脑必须在同一局域网（连接同一个 Wi-Fi），否则无法连接。
5 连接成功，拔掉 USB

连接成功后，程序会弹出提示 「设备已通过 WiFi 连接，现在可以拔掉 USB 线了」。此时底部状态栏显示 「已连接」，按钮文字变为 「断开设备」。

拔掉 USB 数据线后，只要手机和电脑保持同一 Wi-Fi 网络，即可正常使用 TaskDispatcher 的全部功能。

✅ 输入的 IP 地址会被自动保存，下次连接无需重新输入，程序会使用上次的 IP 自动连接。
💡 程序会每 5 秒 自动检测连接状态。若设备意外断开，会自动尝试重连（最多 3 次），重连均失败后会发送通知提醒用户手动处理。
6 验证功能是否正常

通过程序菜单 「指令(&C)」 可验证无线 ADB 各项功能：

  • 亮屏：唤醒手机屏幕并自动上滑解锁
  • 截屏：获取当前手机屏幕截图并发送通知
  • 息屏：关闭手机屏幕
  • 打开目标APP：在手机上启动指定的应用
  • 关闭目标APP：在手机上强制关闭指定的应用
  • 重启ADB：重启 ADB 服务以解决异常问题

建议先点击 「指令 → 亮屏」，如果手机屏幕亮起并自动解锁，说明无线 ADB 完全正常，所有链式任务均可执行。

⁉️ 常见问题（无线连接）
  • 问：无线连接提示无法连接？
    答：检查手机和电脑是否在同一 Wi-Fi 下；关闭手机 VPN 或热点；尝试点击「指令 → 重启ADB」后重试。
  • 问：手机重启后无线 ADB 失效了？
    答：正常现象，手机重启后需重新插 USB 线，点击「连接手机」按钮让程序自动切换为无线模式。
  • 问：TaskDispatcher 可以自动重连吗？
    答：可以。程序会每隔 5 秒检测连接状态，断线后自动尝试重连（最多 3 次），3 次均失败后会发送通知提醒用户手动处理。
  • 问：无线 ADB 比 USB 慢吗？
    答：日常指令（唤醒、启动 APP、截图）延迟差别极小，不影响 TaskDispatcher 的链式任务执行。
  • 问：点击「连接手机」后提示 ADB 初始化失败？
    答：请确认手机已通过 USB 连接且授权了调试权限，USB 连接模式为「文件传输 (MTP)」。若仍失败，尝试「指令 → 重启ADB」后重连。
🔒 MIUI / HyperOS ADB 限制说明
为什么小米手机执行 adb shell input tap 没反应或报错？

MIUI 和 HyperOS 出于安全考虑，默认禁止 ADB 向系统注入输入事件（缺少 INJECT_EVENTS 权限）。即使 ADB 连接正常，input tap / swipe / keyevent / text 也会被系统拦截，表现为无响应或抛出 SecurityException。

如何正确开启 ADB 模拟点击权限？（标准解法）

进入手机 设置 → 更多设置 → 开发者选项（若未开启：设置 → 我的设备 → 全部参数 → 连续点击「OS版本/MIUI版本」7次）。开启以下三项：

  1. USB 调试（基础开关）
  2. USB 调试（安全设置） ← 关键！允许 ADB 模拟点击/按键注入
  3. USB 安装（如需用 ADB 安装 APK）
⚠️ 「USB 调试（安全设置）」和「USB 安装」通常要求登录小米账号且联网，部分机型还需插 SIM 卡。选项可能置灰，需先登账号。

开启后通过 TaskDispatcher 「指令 → 亮屏」 测试：如果手机亮起并解锁，说明权限已生效。如果仍然无效，继续看下一个问题。

已经开启了"USB 调试(安全设置)"还是不行，怎么办？
  • 屏幕需解锁：锁屏状态下 input 事件通常被忽略，请先点亮屏幕并解锁。
  • 关闭 MIUI 优化：开发者选项页面最底部 → 关闭「启用 MIUI 优化」→ 重启手机（部分 MIUI 14 以前机型需要此步骤）。
  • HyperOS 特例：逻辑同 MIUI，同样只需开「USB 调试(安全设置)」。若选项置灰，先登录小米账号。
  • 撤销重授权：开发者选项 →「撤销 USB 调试授权」→ 重新连接电脑并点击允许。
💡 如果依然失败，请检查 USB 连接模式是否为「文件传输 (MTP)」，部分旧版 MIUI 在「仅充电」模式下会限制 ADB 功能。
"USB 调试(安全设置)"选项是灰色的，点不了怎么办？

这是最常见的情况。原因和解决：

  • 必须登录小米账号（云服务账号），并且保持网络连接（Wi-Fi 或移动数据）。
  • 部分机型要求插入 SIM 卡（尤其刚激活的手机或未插卡设备）。
  • 如果登录账号后仍然灰色，尝试重启手机、重新打开开发者选项页面。
  • 极少数情况需要等待几分钟让账号状态同步。
⚠️ 如果以上都无效，可能是系统版本策略限制。建议咨询小米官方客服或以最新官方公告为准。
Redmi K60 / HyperOS 1.x 有什么特别需要注意的吗？

HyperOS 1.x 上的逻辑与 MIUI 基本一致。重点如下：

  • 务必登录小米账号并联网，「USB 调试（安全设置）」才能亮起。
  • 如果之前开启过 MIUI 优化，建议保持开启（HyperOS 上关闭 MIUI 优化可能导致异常）。
  • ADB 版本建议使用最新的 platform-tools（至少 34.0.0+）。
  • 部分 HyperOS 内测版对注入频率有限制，频繁 input tap 可能会被临时屏蔽，稍等几秒再试。

如果方便提供具体的系统版本号（例如 HyperOS 1.0.2.0.UMKCNXM），可以给出更精确的建议。
